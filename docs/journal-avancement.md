## 2026-11-24 — [S] Statistiques : envoi direct à GoatCounter (PR #65, v1.7.1)
Après la v1.7.0, rien ne s'affichait sur GoatCounter. Cause trouvée dans le code de GoatCounter (`zgoat/isbot`) : une requête venant d'une plage d'IP de centre de données (AWS, Google Cloud, OVH…) est classée comme robot et masquée. Avec le proxy Netlify, toutes les visites arrivaient avec l'IP de Netlify, donc toutes masquées. Correctif : le navigateur envoie directement à `https://futurcitoyen.goatcounter.com/count` (`sendBeacon`, repli `fetch` sans cookie), CSP `connect-src` ouverte à cette seule origine, règle `/count` retirée de `_redirects`. Rien à tester avant le merge (comptage en prod seulement). Vérifié en prod : CSP servie, signal parti vers GoatCounter sans erreur en console. Mentions légales complétées en parallèle (RGPD : base légale, durée de 8 h, transfert de Netlify encadré par le Data Privacy Framework) ; démarches de l'utilisateur (contrats de sous-traitance, registre, numéro pro) regroupées dans une carte « action admin ».
